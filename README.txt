AVERNO — STATIC WEBSITE

QUICK START
Extract the entire ZIP to one folder and open index.html in your browser.
No build, installation, Internet connection, backend or API keys are needed.
Keep index.html, styles.css, script.js and favicon.svg together.
Optional development server: from this directory run
  python3 -m http.server 8000
Then open the server in your browser. The server is optional, not a dependency.

FILES
index.html: complete English US website and four expandable draft policies.
styles.css: responsive layout, system fonts, CSS infographic, reduced motion.
script.js: mobile menu, country switcher, optional service guide, form preview.
favicon.svg: local icon. No third-party assets are loaded.

BEHAVIOR
The form is intentionally disconnected. Clicking submit always shows:
“Your request could not be sent. Please try again later”.
Invalid required fields also receive accessible error messages.
No fetch, XHR, analytics, cookies, browser storage, payment, uploads or wallet
connections are implemented. With JavaScript disabled, the submit button stays
disabled, country information is all visible, and native FAQ/policy disclosures work.
Country selection only changes displayed country content, never tax rates or fees.
The optional service guide retains choices in page memory only. Back, Skip and
Start over work without any delays or forced navigation.

COMPATIBILITY
Uses classic deferred JavaScript, native form controls, Grid/Flexbox and local
system fonts. No modules, remote fonts, dialog, :has(), CSS nesting, backdrop
filters or view transitions. Layout includes narrow-screen and reduced-motion
fallbacks. Safari iOS 18 and reasonably recent earlier Safari releases are targeted;
actual iOS device validation is still required before publication.

REQUIRED BEFORE PUBLICATION
1. Replace pre-launch disclosures with verified legal entity, registration,
   business address and operational contacts. Never publish invented credentials.
   No example email or placeholder legal identity is displayed.
2. Confirm availability and appropriately qualified professionals in each country,
   including restrictions on tax advice, filing, financial reporting and payroll.
   Canadian English scope excludes Quebec. Do not imply universal filing rights.
3. Confirm service scope, written engagement, final fees, currency, applicable
   taxes, cancellations/refunds and consumer rights. All displayed prices are
   illustrative preliminary USD starting points.
4. Have all four policy drafts reviewed for actual business operations and local
   law. Specify controller, hosting/logging, retention, rights contact, processors,
   international transfers, governing law and dispute handling as applicable.
5. Either keep the form explicitly unavailable or implement and test a secure
   backend with validation, appropriate privacy disclosures, abuse protection,
   retention rules and truthful success/failure handling. Review the no-JS path.
   Do not enable real-data collection while retaining the current privacy claims.
6. Agree a separate secure document workflow. Never request seed phrases or keys.
7. Audit actual hosting for logs, cookies and injected trackers. Implement consent
   only where required by added functionality/law; do not add deceptive notices.
8. Test real Safari/iOS devices, keyboard, screen reader, zoom, mobile layout,
   contrast, links and all form states. Configure HTTPS and hosting security headers.
9. Do not add fabricated reviews, statistics, licenses, outcome guarantees,
   investment recommendations, cloaking or hidden redirects. No Google Ads
   approval or guaranteed turnaround is claimed.

This archive is a functional pre-launch website, not an operational accounting
business or a connected inquiry service. Policy drafts require review.

INTRODUCTION UPDATE
A dismissible branded introduction animates the logo and changes from a loading
message to useful service context when the document actually finishes loading.
There is no artificial waiting period, countdown, fake progress or required
consent. Continue, Skip, Close and Escape dismiss immediately. Focus is managed
and returned to the page; reduced-motion is respected. No preference is stored.
Deep links skip the introduction. With JavaScript off it is not shown.
Repeated preview labels have been reduced; the footer retains the project status,
the form retains its unavailability warning, and policies remain review drafts.

CONTENT CLEANUP
Removed the placeholder contact and the public list of missing company details.
The form still states that online submission is unavailable. No company identity
or credentials have been invented. Policy review notes remain applicable.

LOADING MOTION
The introduction includes an indeterminate green loading bar while the document
loads and a short completion animation when it is ready. It does not imply that
client records are being accessed or analyzed. There is no fabricated percentage,
forced delay or disabled exit. Reduced-motion removes the animation.

SEPARATE INTRO SCREEN
A full-screen brand entrance now precedes the welcome dialog. Its two-second
bar is a decorative brand transition, not fabricated network progress. Skip and
Escape exit immediately. Reduced motion skips the transition. The welcome
opens once the entrance finishes and the document is ready. Public draft labels
were removed; the policy texts still require review before production use.
